# FCPL lab — C#, 2026–27

This is the lab for the **FCPL** course. It runs as **SharpQuest**, the quest to learn C#, so you'll see that name in some places: the template for your repository, the `sq` helper, and some code. SharpQuest and the FCPL lab are the same thing.

One semester. One project you choose in session 1 and build, one layer per lab, until the end.

## Get the files

**Code → Download ZIP** on this page, then unzip. Or, if you already use git:

```
git clone https://github.com/x86bogdan/fcpl-2026
```

## Session 1

1. A finished project, running, so you can see where this goes
2. A demo involving a password, a compiled program, and no source code
3. Getting .NET working on your machine: `dotnet --version`
4. The [placement task](placement/README.md): 20 minutes, **not graded**. It tells you which route suits you
5. [The contract](CONTRACT.md): how labs are scored, what happens if you miss one, the AI policy
6. **You choose your project, claim an avatar, create your repository, and make your first commit**
7. A quick vote on what we call a couple of things

### What you leave with

- A project that's yours for the semester
- An avatar, which is your name on the scoreboard
- Your own repository, with one commit in it
- A route (guided or project), changeable until session 3
- No homework

### Your repository

Your repository is made from the course template (the SharpQuest template), in the browser, in session 1:
<https://github.com/x86bogdan/sharpquest-2026> → **Use this template**. The steps are in its README.
You don't need git for session 1. Cloning and pushing start in session 2.

## Before session 2

Nothing. Session 2 builds the data model for whatever you chose.
